# D.PAO 数字梳妆台

面向手机浏览器的开瓶产品管理应用，延续原型的米白与酒红配色。使用 Vue 3 + Vite，依赖随构建打包，不依赖运行时 CDN。

## 本地开发

需要 Node.js 22 或 24。

```sh
npm ci
npm run dev
```

```sh
npm test
npm run build
```

## 使用流程

收录产品（照片可选）→ 填写开封日期及瓶身 PAO 月数 → 查看剩余天数 → 更新余量 / 用完评价 / 停用归档。自定义分类直接输入。照片自动缩放至最长边 640px，以减少本地存储占用。

数据仅保存在当前站点、当前浏览器的 localStorage。沿用 `dpao_data_v4` 并兼容旧余量格式；更换域名或端口不会自动带入旧站点数据。请在原站点导出后，在本应用中导入。备份支持原始记录数组或本应用导出的 JSON。导入会替换现有数据并要求确认。

7 天复查是应用内日期提示，需要用户再次打开页面，不包含后台推送、邮件或系统通知。PAO 以品牌和包装说明为准，未标识产品需自行查证；不建议通过转作其他用途继续使用超期产品。

## 验证

`npm test` 覆盖月末和闰年的期限计算、日期边界、旧数据兼容及备份校验。浏览器端测试位于 `tests/browser.spec.js`，先启动开发服务器，再运行 `npx playwright test`（默认使用 `/usr/bin/chromium`，可用 `CHROMIUM_PATH` 指定其他 Chromium 可执行文件）。
